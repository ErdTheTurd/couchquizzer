Support

Couchquizzer is a party trivia game for Apple TV. The TV hosts the room and shows the scores. Everyone else answers from their phone on the same Wi-Fi.

A few things worth knowing

  • The Apple TV is the host. Phones join with the 4-letter room code on the screen.
  • Players need to be on the same local Wi-Fi. The game is not designed to need an internet game server or a subscription.
  • Each question lasts 12 seconds. A correct answer is 100 points, plus 10 for every second left on the clock.
  • You can also play a solo or demo game from the TV while the phone companion is being finished.

Get in touch

Write to support@couchquizzer.com. That reaches Edward Dunn. If the mailbox is not receiving mail yet while the domain is being set up, please try again in a little while, or open an issue on the Couchquizzer GitHub repository.
